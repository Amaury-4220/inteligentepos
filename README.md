# InteligentePOS

Sistema POS Inteligente con arquitectura multiagente.

## Características

- Gestión de ventas
- Gestión de inventario
- Clientes y créditos
- Cuentas por cobrar
- Control de caja
- Reportes y estadísticas
- Trazabilidad completa
- Automatización mediante IA

## Arquitectura

El sistema utiliza agentes especializados para:

- Inventario
- Ventas
- Créditos
- Reportes
- Auditoría
- Atención al usuario
- Análisis de negocio
